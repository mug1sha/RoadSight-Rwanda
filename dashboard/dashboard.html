About RoadSight Rwanda

RoadSight Rwanda is a Big Data analytics project by Group D (2026) that analyses road accident risk patterns across Rwanda using machine learning.

Dataset: 3,007 accidents, 2022–2025, 5 provinces, 35 features.

Models: Random Forest (macro F1 = 0.320) and XGBoost (macro F1 = 0.265).

Stack: Python · Pandas · scikit-learn · XGBoost · Plotly · Tailwind CSS.
